# <BRAIN-NAME> — journal (raw evidence inbox)

Evidence seen but not yet turned into facts. **Append only. Newest at the bottom.**

This file is an **inbox, never an answer source.** A fact becomes ✅ from the proof inside an
entry, not from the entry existing. ANSWER mode never quotes this file.

**Drain it at capture time**, and at the end of a session. An entry that has been turned into a
fact gets ` → F-nnn` appended; it is not deleted, so the trail from raw evidence to fact stays
readable.

Why keep it at all: evidence often appears mid-task, when stopping to write a proper fact block
would interrupt the work. One line here costs nothing and loses nothing.

## Format

```
- <date> — <zone> — <what was seen> — `<command or file:line>` — <the key output line> → F-nnn
```
